# ADR 0002: Keep top_k = 8

Status: accepted

## Context
The case `gdp-2026-oct` fails because the chunk stating the 2026 GDP figure (score 0.734) ranks 9th, while the 8th chunk scores 0.735. The obvious fix is a larger top_k.

## Decision
Run the full evaluation with top_k = 8, 10 and 12 and keep the value with no regressions.

| top_k | Failing cases |
|---|---|
| 8 | gdp-2026-oct |
| 10 | pii-email-sin (gdp-2026-oct now passes) |
| 12 | gdp-2026-oct, cpi-feb-apr, infl-jan-report |

Chosen: 8. `gdp-2026-oct` is recorded as a known issue with its root cause.

## Consequences
- A larger context made the 7B model worse, not better, and the effect was not monotonic. Tuning against a single case would have traded one failure for another.
- Retrieval is the real problem: the embedding model barely separates report dates. Date-aware retrieval and hybrid search are on the roadmap.
